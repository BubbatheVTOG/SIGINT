# SIGINT Dotfiles

GNU stow-managed dotfiles for two Hyprland hosts: `sigint` (Asahi/Fedora ARM laptop) and `matt` (Arch x86_64 desktop).

## Layout

```
dotfiles/
├── common/    # Shared configs (stowed on both hosts). Only host-safe content:
│              #   identical files, or existence-guarded logic (see below).
├── sigint/    # Laptop-specific (Asahi, lid, battery, eDP-1)
├── matt/      # Desktop-specific (3 monitors DP-4/5/6, GPU passthrough, no laptop keys)
└── system/    # System-wide configs (/etc, e.g. greetd). Shared by both hosts.
│              #   Stowed to / with sudo, NOT to $HOME.
```

### The common/ rule

These are two different OSes (Arch x86_64 vs Fedora Asahi ARM). Anything in
`common/` must be either:

1. **Identical on both hosts**, or
2. **Guarded** — e.g. `[ -f "$HOME/.cargo/env" ] && . "$HOME/.cargo/env"`, or a
   `case "$(hostname)"` branch (see `toggle-theme.sh`).

Host-divergent paths, binaries, workarounds, and hardware quirks go in the
host package (`matt/` or `sigint/`), never in `common/`. Example:
`OPENCODE_BIN_PATH` is a matt-only workaround and is set conditionally in
`common/.zshrc.local` only when the binary exists.

## Install

On **sigint**:
```bash
stow -R -t ~ common sigint
```

On **matt**:
```bash
stow -R -t ~ common matt
```

System-wide configs (greetd), on both hosts:
```bash
sudo stow -R -t / system
```

Requires packages: `greetd greetd-tuigreet` (then `systemctl enable greetd`).

## Theme Toggle

`SUPER + SHIFT + R` flips between teal (default) and red across Hyprland, Waybar, Kitty, Rofi, Tmux, and Hyprpaper wallpaper.

Both hosts use the same wallpaper pair: `teal.jpg` (teal theme) and `red.jpg`
(red theme). `teal_web.jpg` is also available in `common/.config/hypr/wallpapers/`
if you want a third option.

## Secrets

Secrets (API keys, tokens) live in `~/.config/secrets` (gitignored) and are sourced by the shell. Configs reference them via opencode's `{env:VAR_NAME}` substitution. Required variables:

```bash
export HTB_TOKEN="..."      # HackTheBox MCP bearer token
export VLLM_API_KEY="..."   # vllm provider key
```

## Notes

- Matt's monitors are configured in `matt/.config/hypr/hyprland.lua` (DP-4/DP-5/DP-6 with rotations) — verified against `hyprctl monitors`.
- opencode config is per-host (`matt/.config/opencode/`, `sigint/.config/opencode/`): `opencode.json` + `package.json`. `bun.lock` is gitignored (regenerated by `bun install`).
- `bun.lock`, `.zdirs`, `.zcompdump*`, `*.bak`, and `.config/secrets` are gitignored.
- After pulling changes, re-run the `stow` command for your host to refresh symlinks.
